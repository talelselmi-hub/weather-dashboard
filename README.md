🌤️ Weather & Interactive Map Dashboard
Un tableau de bord météo interactif et responsive combinant l'API OpenWeatherMap et la cartographie Leaflet.js,

🚀 Fonctionnalités principales
Météo en temps réel : Affichage instantané de la température (°C), du statut météo, de l'humidité (%) et du vent (km/h) pour n'importe quelle ville.

Carte interactive dynamique : Repositionnement automatique de la carte Leaflet et ouverture d'un marqueur d'information à chaque recherche.

Historique des recherches : Sauvegarde locale (localStorage) des 4 dernières villes recherchées sous forme de boutons d'accès rapide.

UX/UI Soignée : Indicateur de chargement (loader) pendant les requêtes et palette de couleurs sombres ajustée pour un contraste optimal.

🛠️ Technologies utilisées
HTML5 & CSS3 (Flexbox, CSS Grid, Thème custom Dark Brown)

Vanilla JavaScript (Async/Fetch API, DOM Manipulation, LocalStorage)

OpenWeatherMap API (Données météo et coordonnées geocode)

Leaflet.js & OpenStreetMap (Cartographie interactive)
